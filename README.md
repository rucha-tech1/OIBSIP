# ATM Interface

## Project Overview

ATM Interface is a console-based Java application that simulates the basic operations of an ATM machine.

The application allows users to log in using their User ID and PIN and perform different banking transactions.

## Features

- User ID and PIN authentication
- Maximum 3 login attempts
- Check balance
- Withdraw money
- Deposit money
- Transfer money
- Quick Cash
- Transaction History
- Mini Statement
- Change PIN
- Account Details
- Transaction Receipt
- Insufficient Funds validation
- Date and time for transactions
- Transfer confirmation
- Multiple user accounts

## Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- Scanner
- LocalDateTime
- Switch Case

## Java Classes

The project contains five Java classes:

1. ATM.java - Handles ATM operations and menu
2. Account.java - Stores account information and balance
3. Transaction.java - Stores transaction details
4. Bank.java - Manages bank accounts and transfers
5. Main.java - Starts the application
